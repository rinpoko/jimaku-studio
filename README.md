# 字幕スタジオ

動画の音声を Google の AI（Gemini API）で聞き取り、日本語に翻訳して、話しているタイミングに合わせて字幕をのせる Web アプリです。Chrome / Edge では PWA としてインストールして使えます。

**使う → https://rinpoko.github.io/jimaku-studio/**

## 特長

- 動画はブラウザの中だけで処理します。Google に送るのは、動画から取り出した**音声だけ**です。
- 聞き取りと翻訳は 1 回のリクエストでまとめて行います。長い動画は、話の切れ目で 3〜10 分ずつに分けて送ります。
- 字幕の一覧で、訳文・原文・タイミングをその場で直せます。
- 書き出せるもの：
  - 字幕入り動画（MP4、ブラウザ内で作成）
  - SRT
  - VTT
- 処理の途中でタブを閉じても、あとで「再開」を押せば続きから処理できます。
- データ（字幕・音声・設定）は、使っている端末のブラウザ内にだけ保存されます。

## はじめかた

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを作ります（無料、クレジットカード不要）。
2. アプリの「⚙ 設定」にキーを貼り付けて保存します。
3. 動画をドラッグ＆ドロップします。

## 注意

- **Gemini API の無料枠では、送った音声や文章が Google のサービス改善に使われることがあります。** 人に見せたくない動画には使わないでください。
- 無料枠には、1 分あたり・1 日あたりの回数制限があります。
  - 上限に達すると自動で待ってから続けます。
  - 1 日の上限に達した場合は、太平洋時間の 0 時（日本時間 16〜17 時）以降に「再開」を押してください。
  - Flash-Lite 系のモデルは 1 日の回数が多いので、長い動画に向いています。
- 字幕のタイミングは、AI の推定に音量の変化を組み合わせて合わせています。ずれた字幕は、一覧の「◀ 0.2s / 0.2s ▶」で調整してください。
- 対応ブラウザはパソコン版の最新の Chrome / Edge です。動画処理に WebCodecs を使っています。

## 仕組み

| 処理 | 使っているもの |
|---|---|
| 音声の取り出し・字幕の焼き込み | [Mediabunny](https://mediabunny.dev/)（WebCodecs、MPL-2.0） |
| 聞き取り＋翻訳 | Gemini API `generateContent`（構造化 JSON 出力） |
| 保存 | IndexedDB / localStorage |

ビルド不要の静的サイトです。ローカルで動かすには、次のコマンドを実行して http://localhost:8771 を開きます。

```bash
python3 -m http.server 8771
```
